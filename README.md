# 🔐 The Password Web

一个轻量、可本地运行的密码管理器。  
支持主密码解锁、本地 AES-GCM 加密存储，以及 2FA 动态验证码。

> 本仓库仅包含前端源码，直接用浏览器打开 `index.html` 即可使用。

---

## ✨ 功能

### 密码库

- 添加密码条目（名称、账号、密码、备注，可选 2FA 密钥）
- 随机生成 16 位强密码（大小写 + 数字 + 符号）
- 修改、删除条目（删除前二次确认）
- 一键复制账号 / 密码 / 动态验证码
- 条目内密码默认掩码，可单独点击「显示」查看
- 关键词搜索（名称 / 账号 / 备注 / 2FA），带匹配计数与一键清空
- 存储方式标识（加密存储 / 明文存储）实时显示在顶栏

### 2FA

- 添加 Base32 密钥后，列表中实时显示 6 位动态验证码
- 30 秒自动刷新，并显示剩余秒数
- 保存时会校验 Base32 字符合法性

### 安全

- 主密码解锁，PBKDF2（200,000 次，SHA-256）+ AES-GCM 加密后写入 `localStorage`
- 「在当前标签页保持解锁」：可选的会话内免重复输入，关闭页面即失效
- 自动锁定：可选 1 / 5 / 15 分钟无操作后自动回到解锁界面
- 安全设置页：关闭 / 开启主密码、修改主密码、清空本机数据（双重确认）

### 交互

- 页内 Toast 提示与模态对话框，替换原生的 `alert` / `confirm` / `prompt`
- 表单行内校验提示，不再弹出系统对话框打断操作
- 列表使用事件委托，无内联 `onclick`
- 键盘快捷键：
  - `Ctrl / ⌘ + K`：聚焦搜索框
  - `Esc`：关闭弹窗 / 取消编辑
  - `Enter`：提交当前表单

## 🎨 界面

- 浅蓝 + 浅粉主题，卡片式布局，统一的间距 / 圆角 / 阴影设计变量
- 桌面端为「左侧编辑表单 + 右侧密码列表」两栏布局，侧栏随页面滚动固定
- 移动端自动切换为单列，条目信息改为纵向排列
- 所有表单控件等高、对齐；按钮具有 hover / focus / disabled 状态
- 支持 `prefers-reduced-motion`，尊重系统的减少动画设置

## 🔒 安全说明

- 本项目为**纯前端本地存储方案**，数据保存在用户设备的浏览器存储中。
- 密码库内容通过 Web Crypto API（PBKDF2 + AES-GCM）加密后保存，`localStorage` 中仅存密文。
- 主密码不会明文存储，请务必牢记；若遗忘，无法解密已有数据。
- 关闭主密码后将改为明文存储，请自行评估风险。
- 「保持解锁」仅写入当前标签页的 `sessionStorage`，关闭标签页即失效。

> 提示：本项目适合个人轻量使用与学习用途。  
> 对于高安全场景，建议结合系统级安全存储、云端同步策略与专业审计方案。

## 📁 项目结构

```text
.
├── index.html      # 密码库主页面（解锁 / 编辑 / 列表）
├── security.html   # 安全设置页面
├── style.css       # 统一设计系统与全部样式
└── script.js       # 存储加密、2FA、UI 基元与页面逻辑
```

数据存储键（保持向后兼容，旧数据可直接解锁）：

| 键 | 说明 |
| --- | --- |
| `pm_secure_v1` | 加密后的密码库 `{ salt, iv, data, updatedAt }` |
| `pm_plain_v1` | 关闭主密码时的明文库 |
| `pm_mode_v1` | 存储模式：`secure` / `plain` |
| `pm_autolock_v1` | 自动锁定分钟数（`0` 表示关闭） |
| `pm_session_pwd_v1` | 会话内保持解锁时使用（`sessionStorage`） |
